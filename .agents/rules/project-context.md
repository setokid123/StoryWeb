# StoryWeb workspace rule

This repository is shared with Codex and Claude Code. Read `AGENTS.md`, `docs/ADS_UNLOCK_PLAN.md`, `docs/DESIGN_SYSTEM.md`, and `docs/WORKBOARD.md` before modifying files.

Your responsibility is design and code for presentation only: responsive layouts, presentational components, interaction visuals, accessibility, and the design system. Claude Code owns all client/server state, API calls, validation, authorization, and ad provider logic. Build typed views receiving data and callbacks via props. Claim the task in `docs/WORKBOARD.md` and list the files you will edit. Coordinate changes to `src/app/globals.css`, `package.json`, and shared components before touching them.

Use Vietnamese copy. Keep the reading experience calm and focused. Preserve current routes and component contracts unless a task explicitly changes them. Provide a screenshot or concise walkthrough when handing off design work. The locked chapter currently has a 5-minute server-signed click session; U4 adds views for two selectable unlock modes, while Claude implements the logic. Label external links clearly; do not auto-open a browser popup or auto-redirect readers.
