# StoryWeb workspace rule

This repository is shared with Codex and Claude Code. Read `AGENTS.md`, `docs/DESIGN_SYSTEM.md`, and `docs/WORKBOARD.md` before modifying files.

Your default responsibility is UI/UX: responsive page layouts, interaction states, accessibility, visual consistency, and the design system. Claim the task in `docs/WORKBOARD.md` and list the files you will edit. Coordinate changes to `src/app/globals.css`, `package.json`, and shared components before touching them.

Use Vietnamese copy. Keep the reading experience calm and focused. Preserve current routes and component contracts unless a task explicitly changes them. Provide a screenshot or concise walkthrough when handing off design work. The locked chapter has an on-site gate dialog and a 5-minute server-signed click session. Keep the external-link action clearly labeled and behind its configuration gate; do not auto-open a browser popup or auto-redirect readers.
